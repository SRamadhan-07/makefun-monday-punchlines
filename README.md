# Monday Morning Punchlines

A tiny Python program that writes one Monday morning punchline to `/output/entry.txt`: Monday arrives like an unscheduled update — nothing improved, and everything needs a restart. The joke is stored as data in the program and written exactly, with no extra output.

## How to run

```bash
python3 main.py
```

This creates `/output` when needed and writes the entry text to `/output/entry.txt`.
